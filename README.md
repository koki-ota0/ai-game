# ECHO//ABYSS

**過去の自分と、未来を切り拓け。**

数秒前の移動と射撃を再生する「残響」と共闘する、ブラウザ向け時間アクション・ローグライトです。近敵へのオート射撃と、マウスによる自由照準・手動連射を併用できます。外部APIやAPIキーは不要です。

## 遊ぶ

```bash
npm install
npm run dev
```

表示されたURLを開き、フレーム・モード・難易度を選んで開始してください。INFINITE は最初から選択でき、LEVEL はレベル001から順に解放されます。

### 操作

| 入力 | 行動 |
| --- | --- |
| `WASD` / 矢印キー | 移動（初回は「YOU」マーカーが自機を案内） |
| マウス左長押し | 照準方向へ手動連射（オート射撃より20%高速） |
| マウス右クリック / `R` | フレーム固有の武器スキル（左で射撃しながら同時発動可能） |
| `SPACE` / 左`SHIFT` | 位相ダッシュ（発動中は無敵） |
| `E` | 残響召喚（過去の移動と射撃を再生） |
| `Q` | ZERO FIELD（ゲージ100%で発動） |
| `ESC` | 一時停止 / 再開 |
| `1` `2` `3` | 進化を選択 |
| 進化画面で `R` | 進化候補を再構成 |

タッチデバイスでは、仮想スティックと **SKILL / ZERO / ECHO / DASH** の4ボタンを使用できます。ゲームフィールドを長押しすれば、照準・手動射撃も可能です。

## ゲームモード

### INFINITE

STANDARD / ABYSSを選べる、最大100セクターの長期モードです。40秒ごとのセクター進行、ランダムな時間異常、3セクターごとのワーデン戦が続きます。10・20…90セクター終了時には、その時点のスコアと最深セクターを保存したうえで、次の10セクターへ進むか、その時点で **TIME CLEAR** として終えるかを選択できます。セクター100を終えると選択なしで結果を確定します。任意終了時に特別なスコアボーナスは加算せず、表示中の得点をそのまま記録します。LEVEL の永続EXP・初期ボーナスとは分離しています。

通常敵の新種は、INFINITEでは2ラウンドごとに最大1種類だけ追加します。初期のドローン・ダートに、ラウンド02・04・06・08・10でガンナー → スプリッター → タンク → スナイパー → ウィーバーの順で解禁されます。LEVELも同じ順序を、従来のより緩やかな編成ティアで解禁します。高耐久のタンクは解禁直後の同時出現を2体までに制限し、INFINITEでは2ラウンドごと、LEVELでは編成ティアごとに上限+1・最大12体で緩和します。上限中はほかの解禁済み敵へ振り替えるため、全体の出現数は維持されます。

セクター移行時には、キル扱いにせず通常敵の約3分の1を退場させます。その後2.4秒は通常敵もワーデンも出現せず、新しいラウンドの開始時に短い間合いが生まれます。

#### 10セクターごとの脅威増幅

深度は `floor((セクター - 1) / 10)` です。セクター11・21…から、通常のセクター成長に加えて次を複利・累積適用します。

- 通常敵HP：`1.12 ^ 深度`
- ワーデンHP：`1.16 ^ 深度`（通常敵より強めの成長）
- 出現頻度：`1 + 深度 × 0.03`
- 同時出現上限：基本値に `深度 × 3` 体を加算（STANDARDは最深部で152体）
- 敵攻撃力への深度倍率はなし。従来の緩やかなセクター成長だけに限定しています。

ABYSSは、敵HP ×1.55、ワーデンHP ×2、出現頻度 ×1.4、敵速度 ×1.1、同時出現上限 ×1.2、エリート率 +0.07、敵攻撃力 ×1.2です。最低出現間隔へ達した後も密度差を維持します。スコア倍率は従来どおり ×1.5で、攻撃力だけを極端に上げるのではなく、耐久・密度・速度を主な難度差にしています。

### LEVEL — 全100ステージ

10区域×10深度の全100ステージです。区域選択を左右に切り替え、解放済みのステージを選びます。各ステージは32〜50秒の戦闘後にワーデンが出現します。

**クリア条件は、ワーデンと全ての残敵を倒すことです。** ワーデン撃破直後にクリアにはならず、新たな通常出現が止まる掃討フェーズへ移行します。ボスが召喚した敵、スプリッターから生まれた小型敵も残数に含まれ、残敵ゼロで初めてクリア・EXP付与・次ステージ解放が行われます。

#### 永続EXPと初期ボーナス

- 初クリアEXP：`120 + ステージ番号 × 10`（レベル001で130、レベル100で1,120）。
- 再攻略でも初回の35%を獲得できます。短いステージの周回だけで即座に上限へ到達する設計ではありません。
- 初期ボーナスポイント：`Math.min(120, Math.floor(Math.sqrt(累積EXP / 18)))`。
- ポイントを割り振ってもEXPは消費しません。メニューの **初期ボーナスを編集** から、いつでも無料で＋／－・全リセットできます。
- 6系統とも1ランク20上限、全120ポイントです。未獲得のポイントを外部指定だけで使うことはできません。

| 初期ボーナス | 1ランクの効果 | 計算 |
| --- | ---: | --- |
| 武器出力 | 武器ダメージ +8% | ランクごとに乗算 |
| 時間加速 | 攻撃速度 +6% | ランクごとに乗算 |
| フレーム耐久 | 最大HP +10% | ランクごとに乗算 |
| 残響同調 | 残響の武器ダメージ +8% | ランクごとに乗算 |
| 機動制御 | 移動速度 +4% | ランクごとに乗算 |
| 欠片共鳴 | ステージ内EXP +8% | ランクごとに乗算 |

**ステージ内のレベル・欠片EXP・ドラフト進化は、次のステージ／リトライでリセットされます。** 永続初期ボーナスだけを新しい基本性能へ適用し、通常の進化スタックを消費しません。リザルトの「次のレベルを準備」から、獲得したポイントを割り振って次へ進めます。

#### 100ステージのスケーリング

- 敵HP：`1.02 ^ (ステージ - 1)`、レベル100で約 **×7.10**。
- 敵攻撃力：`1.013 ^ (ステージ - 1)`、レベル100で約 **×3.59**。
- 敵編成・エリート率・速度・出現間隔は別カーブで調整し、レベル100の通常出現は同時60体で停止します（分裂・ボス召喚を除く）。
- ワーデンはレベル001・026・051・076で段階的に強化され、076以降は低HPでPHASE 04へ移行します。
- 敵HPだけを急激に伸ばすのではなく、永続％ボーナス・ステージ内進化・手動照準を組み合わせて対応するバランスです。

固定値のまま後半で機能しにくい強化も見直しています。被ダメージ軽減は12%（複数取得は乗算）、ダッシュ斬撃は武器ダメージの280%、残響の消滅爆発は武器ダメージの270%開始、撃破回復は最大HPの2.5%、回復ドロップは最大HPの18%、SYNC RIFTの回復は最大HPの15%です。

## 開始時のバランス

- 両モードとも、素の武器ダメージは従来の **×0.90**、基礎クリティカル率は **0%** です。クリティカル進化を取得すれば、従来どおり率・倍率を伸ばせます。
- INFINITE はそこから開始素体を **武器ダメージ ×0.92・攻撃速度 ×0.97・最大HP ×0.97** に調整します。旧初期値からの最終ダメージ倍率は **×0.828** です。
- WRAITHの基礎攻撃力は15 → **23**です。無補正の実ダメージはINFINITE **19.044**、LEVEL **18.63**で、両モードとも開始直後のドローン・ダートを通常2発で撃破できます。
- ドローンHP36、ダートHP34とし、TEMPESTの連鎖集中を含む通常1射でも開始直後のワンショットは抑制しています。BASTIONは照準重弾の進路上に全方位弾が常に重ならないよう、リング射角を半分ずらしています。
- LEVEL はINFINITEの追加補正を引き継がず、共通補正から **武器ダメージ ×0.90・攻撃速度 ×0.95・最大HP ×0.95** を適用してから永続ボーナスを乗算します。永続ボーナスなしの武器ダメージは旧初期値の **×0.81** で、引き続きINFINITEより低い初期性能です。
- 弱体化後の撃破速度に合わせ、LEVELでは敵が強いステージほど通常出現の待機時間を考慮します。開始を難しくしすぎず、後半に敵が溜まりすぎることも防ぎます。
- INFINITEの開始能力は、ダッシュ **2.8秒**、残響 **12秒**、武器スキルはフレーム別基本値の **1.2倍** のクールダウンです。LEVELは従来の2.4秒・10秒・基本武器スキル冷却を維持します。

## 戦闘システム

- **3フレーム**：安定した遠距離連射の WRAITH、集団を連鎖雷撃で制圧する TEMPEST、全方位射撃と重い照準弾を使う高耐久 BASTION。
- **能動武器スキル**：WRAITH は「貫通レール」、TEMPEST は「連鎖サンダー」、BASTION は「ノヴァバースト」を `R` / 右クリックで発動。
- **残響**：数秒前の自分を複製。移動と射撃タイミングは過去どおり再生しつつ、斉射の中心方向を現在の近敵へ自動補正します。WRAITHの拡散とBASTIONのリング間隔は維持され、現在の強化値も反映されます。
- **共鳴**：自分と残響が短時間に同じ敵へ攻撃すると追加ダメージ。武器火力を参照するため、後半でもスケールします。
- **ZERO FIELD**：敵と敵弾を遅延させ、自分の攻撃を加速。ダッシュ・武器スキル・残響も即座に回復します。
- **SYNC RIFT**：無限のセクター02・レベル002以降に現れる任意目標。円内で累計4秒維持すると、ZERO +35・最大HPの15%回復・欠片を獲得。円の外では進行が減らず保持されるため、再入場後に続きから安定化できます。
- **29種類の進化**：火力 +25%、攻撃速度 +20%、最大HP +20%など。専用アイコンと具体的な効果説明付きで、フレームに合わない候補は出現しません。
- **フレーム別補正**：WRAITHの高圧貫通は弾ダメージも +18%。TEMPESTは未使用の連鎖を単一敵へ集中。BASTIONの誘導は全方位弾にも専用の探知範囲・旋回速度で機能します。
- **シードと記録**：同じシードへの再挑戦、難易度別・レベル別ハイスコア、最深セクター、100ステージの解放をサポート。

主な保存キーは `echo-abyss-campaign-xp`、`echo-abyss-initial-bonuses`、`echo-abyss-unlocked-level`、`echo-abyss-level-{id}-clear`、`echo-abyss-best-level-{id}` です。無限モードの記録とは分かれています。

## 検証

```bash
npm run build       # TypeScript + production build
npm test            # Playwright 20件
npm run playtest -- 100 wraith STAGE001 level 1 progression fast
```

`playtest` は開発サーバー起動中に、回避・回収・武器スキル・残響・ZERO・RIFTを行うボットで実際に戦闘します。ボス戦では手動照準をボスへ合わせ、撃破後は残敵掃討へ戻ります。ページ例外・ブラウザクラッシュ・予期しないページ遷移も記録します。ログとスクリーンショットは `test-results/` に保存されます。

```bash
# INFINITE（最後の引数でABYSSも指定可能）
npm run playtest -- 90 tempest STORM01
npm run playtest -- 90 wraith ABYSS01 infinite 1 none fast abyss

# LEVEL: duration / frame / seed / mode / stage / meta / render
npm run playtest -- 180 bastion STAGE050 level 50 progression fast
npm run playtest -- 240 wraith STAGE100 level 100 progression fast
npm run playtest -- 180 tempest FINALMAX level 100 max fast
```

`progression` は対象ステージ以前の初クリアEXPだけを使い、火力・攻速・耐久・残響へ配分した非上限編成です。`max` は全120ポイント、`none` は保存済み編成です。`fast` は検証時の描画だけを間引き、ゲームの固定時間刻みや戦闘計算は変更しません。

最終調整後の実戦結果：

- INFINITE / STANDARD / WRAITH：90.2秒でセクター03・86撃破・敵4体・残HP97。ラウンド03の出撃停止後も戦闘継続を確認。ページ例外・クラッシュ・予期しない遷移なし。
- INFINITE / ABYSS / WRAITH：57.9秒でセクター02・71撃破・敵9体・残HP97。ページ例外・クラッシュ・予期しない遷移なし。
- レベル001 / WRAITH / 初期ボーナス0：45.2秒、46撃破、残HP75で残敵掃討後にクリア。
- レベル100 / WRAITH / 到達時点の58ポイント：73.8秒、54撃破、残HP341.0で残敵掃討後にクリア。1,120XPが加算され、累積61,380 → 62,500XP。

## 技術構成

- React 19 + TypeScript + Vite
- Canvas 2Dによる固定時間刻みのゲームエンジン
- Lucideアイコン、同梱フォント、生成キーアート
- PlaywrightによるUI・操作・キャンペーン・モバイルの回帰テスト

主要なゲームロジックは `src/game/GameEngine.ts`、進化は `src/game/upgrades.ts`、100ステージの生成・スケーリングは `src/game/levels.ts`、永続EXPと％初期ボーナスは `src/game/campaign.ts`、UIは `src/App.tsx` と `src/styles.css` にあります。
